# Concord · 知遇

**中文含义：知遇**——不是“选对象”的功利算计，而是灵魂同频后的彼此看见与相逢知己。名称释义分为三组：

- **源起组（Concord 本意）**：和谐、契约一致——源自拉丁语 *concordia*（同心），指双方在根本立场上达成一致、无需勉强的自然状态。
- **表达组（中文语境）**：和睦、心意相合、理念同频——强调相处中的松弛与舒展，是关系长期稳定的基础。
- **意境组（情感底色）**：灵魂同频、彼此契合、相逢知己——偏温润、不冰冷，是两个人在价值观与精神世界里“认出彼此”的珍视感。

三组词义共同指向一件事：这不是一套挑挑拣拣的择偶算法，而是一面帮你看清“是否精神匹配”的镜子，重在契合，而非筛选。

## 一、系统定位

Concord 是一套用于婚恋场景的 **条件筛选标准 + 结果评估系统**，目标不是机械“打分选人”，而是从现实匹配、关系稳定性、长期成长性、情感体验四个层面，帮助你更理性地筛选出适合自己的理想型伴侣。

本仓库包含两部分：

- **方法论文档**（本 README）：定义完整的筛选标准、评分权重与结论分级逻辑。
- **在线评估工具**（[`index.html`](./index.html)）：将上述标准实现为可交互的网页应用，自动完成加权计算、一票否决判断与风险修正，生成可靠、可追溯的评估报告，并通过 GitHub Pages 免费在线部署。

建议把评估拆成三层：

1. **基础门槛层**：先判断“能不能进入了解范围”。
2. **核心匹配层**：判断“适不适合长期相处与发展”。
3. **结果评估层**：输出清晰结论与后续行动建议。

## 二、第一层：基础门槛筛选

这一层只做“硬条件过滤”，避免把时间投入到明显不适合的人选上。

### 1. 个人基础信息

- 年龄区间：是否符合自己的婚恋阶段需求
- 婚姻状态：未婚 / 离异 / 其他情况是否可接受
- 所在城市：是否接受异地、跨城定居
- 学历背景：是否达到自己的基本预期
- 职业类型：工作是否稳定，节奏是否可兼容
- 收入水平：是否满足现实生活基本规划
- 家庭结构：是否存在自己明确不能接受的情况

### 2. 一票否决项

以下建议作为直接淘汰项，不进入下一轮：

- 明显不诚信：隐瞒婚史、债务、重要经历
- 暴力倾向：语言暴力、控制欲、肢体暴力
- 严重成瘾：赌博、酗酒、长期不受控的成瘾行为
- 价值观冲突过大：婚育、忠诚、金钱观完全对立
- 人品风险：长期失信、欺骗、道德底线差

## 三、第二层：核心匹配维度

这一层是系统的主体，建议采用 **100 分制加权评估**。

### A. 价值观与人生方向（25分）

重点看“方向是否一致”，而不是表面条件是否优秀。

- 婚姻观：对婚姻的理解是否一致
- 生育观：是否要孩子、要几个、何时要
- 金钱观：消费、储蓄、投资、负债观念是否匹配
- 家庭观：原生家庭边界、赡养责任、亲密关系排序
- 事业观：看重稳定、成长、自由还是资源积累

评分建议：

- 21-25：高度一致，可形成长期合作关系
- 15-20：大体一致，少数问题可沟通
- 0-14：核心方向冲突较大

### B. 性格与相处体验（20分）

重点看“相处是否舒服、稳定、低损耗”。

- 情绪稳定性
- 是否尊重他人边界
- 沟通方式是否平和直接
- 是否有同理心
- 是否愿意解决冲突，而不是逃避或攻击

评分建议：

- 16-20：相处自然，情绪成熟
- 10-15：可相处，但存在明显磨合点
- 0-9：高消耗、高压力

### C. 现实条件与生活兼容度（20分）

重点看“能不能把日子过到一起”。

- 城市与定居规划
- 工作时间与生活节奏
- 收入与消费结构
- 房车与居住安排预期
- 对家务分工、生活习惯的接受度

评分建议：

- 16-20：现实兼容度高
- 10-15：有可协商空间
- 0-9：落地难度大

### D. 家庭系统与责任感（15分）

重点看“进入婚姻后是否会形成稳定关系系统”。

- 是否能独立处理原生家庭关系
- 是否具备责任意识
- 是否对承诺有执行力
- 家庭相处模式是否健康
- 面对压力时是否会推卸责任

评分建议：

- 12-15：成熟可靠
- 8-11：基本合格，但需观察
- 0-7：风险较高

### E. 成长潜力与长期经营能力（10分）

重点看“未来三到五年是否能一起变好”。

- 是否有自我反思能力
- 是否愿意学习和改变
- 是否有稳定目标感
- 是否能接受共同成长而非彼此消耗

评分建议：

- 8-10：成长型伴侣
- 5-7：潜力一般
- 0-4：长期停滞风险高

### F. 吸引力与亲密感（10分）

重点看“你是否真心愿意靠近对方，而不是只有条件合适”。

- 外在吸引是否达标
- 聊天是否有兴趣和期待
- 肢体与情感亲密边界是否舒适
- 在一起时是否有轻松、安心、被理解的感觉

评分建议：

- 8-10：有明显吸引与亲密意愿
- 5-7：可以培养
- 0-4：缺乏主观心动感

## 四、第三层：结果评估模型

### 1. 总分计算

总分 = 价值观25 + 性格20 + 现实条件20 + 家庭责任15 + 成长潜力10 + 吸引力10

满分 100 分。

### 2. 结论分级

#### S级（85-100分）：高匹配对象

- 基础条件通过
- 核心价值观一致
- 相处感受稳定正向
- 建议：进入深度了解或认真交往阶段

#### A级（70-84分）：值得重点观察

- 整体较匹配
- 局部存在可沟通问题
- 建议：继续接触，针对分歧点专项验证

#### B级（55-69分）：谨慎推进

- 有一定吸引或条件优势
- 但长期稳定性存疑
- 建议：不急于投入感情，重点观察风险项

#### C级（0-54分）：不建议继续

- 核心匹配不足
- 继续投入时间成本较高
- 建议：尽早止损，保持礼貌退出

### 3. 风险修正机制

即使总分高，只要出现以下情况，也应下调一个等级：

- 多次撒谎或信息前后不一致
- 冲突中出现羞辱、威胁、冷暴力
- 对边界、忠诚、责任完全缺乏敬畏
- 对未来规划长期模糊且无行动力

## 五、实际使用方式

建议按以下流程使用：

1. **初筛阶段**：先看基础门槛和一票否决项。
2. **了解阶段**：围绕六大维度做观察和记录。
3. **复盘阶段**：每次接触后简要打分，避免只凭情绪判断。
4. **定级阶段**：累计 3 次以上有效接触后再做最终评估。

## 六、使用原则

- **先看底线，再看上限**：人品和边界感比“优秀条件”更重要。
- **先看长期，再看短期**：婚恋不是一次心动，而是长期合作。
- **先看匹配，再看完美**：理想伴侣不是分数最高的人，而是最适合你的人。
- **系统是辅助，不是替代判断**：任何模型都要结合真实相处体验。
